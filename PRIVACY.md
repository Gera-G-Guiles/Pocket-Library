# Pocket Library Privacy Policy

**Effective date: August 14, 2026**

Pocket Library respects your privacy. The application is designed to work entirely offline and does not collect, transmit, sell, share or track personal data.

## Data Collection

Pocket Library does not collect personal information, usage information, identifiers, location data, analytics or advertising data.

The application does not require an account and does not use advertising, tracking technologies or third-party analytics services.

## User Files and Library Data

Pocket Library only accesses game files, artwork and metadata that the user explicitly selects through the system Files picker.

Selected content is copied into the application's private local container and remains on the device. These files are not uploaded, transmitted or shared by Pocket Library.

The application does not inspect files that the user has not selected.

## Data Storage and Deletion

Imported games, artwork, metadata, preferences and save data are stored locally on the user's device.

Users can remove imported games from within the application. All locally stored application data can also be removed by deleting Pocket Library from the device.

## Network Access

Pocket Library does not provide online accounts, cloud synchronization, game downloads or network-based services.

## Third-Party Services

Pocket Library does not include third-party advertising, analytics, tracking or data-collection services.

Apple may process App Store and device diagnostic information independently under Apple's own privacy policies and the user's device settings.

## Children's Privacy

Pocket Library does not knowingly collect personal information from children or from any other users.

## Changes to This Policy

This Privacy Policy may be updated if the application's functionality changes. Any revision will be published in this repository with a new effective date.
